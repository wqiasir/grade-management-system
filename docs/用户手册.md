# 用户手册 — 杭电计算机学院学生成绩管理系统

> 软件工程课程实践 · R12 交付文档
> 面向读者：系统管理员、教师、学生；部署者请先读「安装与启动」。

---

## 1. 安装与启动

### 1.1 环境要求

- Python 3.12+（开发环境实测 3.12.6）
- git（拉取代码）
- 无需单独装数据库（SQLite 由 Python 自带）

### 1.2 首次部署（Windows PowerShell 为例）

```powershell
cd 项目目录
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 初始化数据库（走 Alembic 迁移；--force 为清空重建）
.\.venv\Scripts\flask.exe init-db
.\.venv\Scripts\flask.exe seed        # 写入演示数据（幂等，可重复执行）
```

### 1.3 启动方式

| 方式 | 命令 | 适用 |
| --- | --- | --- |
| 开发（调试，改代码自动重启） | `.\.venv\Scripts\flask.exe run` | 开发 / 演示 |
| 生产（waitress，多线程） | `python serve.py` | 部署 |
| 生产（指定监听） | `waitress-serve --listen=0.0.0.0:8000 wsgi:app` | 部署 |

浏览器打开 <http://127.0.0.1:5000/>（开发）或 <http://0.0.0.0:8000/>（生产，端口见下）。

### 1.4 密钥与端口配置（R12 起）

复制 `.env.example` 为 `.env`（`.env` 不入版本控制）并修改：

```
SECRET_KEY=<随机 64 位十六进制串，可用 python -c "import secrets; print(secrets.token_hex(32))" 生成>
HOST=0.0.0.0
PORT=8000
```

- `SECRET_KEY` 未配置时应用仍可启动，但会**生成随机临时密钥并告警**（重启后所有人需要重新登录）；
  生产环境**必须**显式配置；
- `.flaskenv` 只保留开发用的 `FLASK_APP` / `FLASK_DEBUG`，不再存放密钥。

### 1.5 演示账号（`flask seed` 创建，仅用于教学演示）

## 2. 管理员操作指南

导航（登录后）：首页 / 账号总览 / 账号管理 / 学生管理 / 教师管理 / 课程管理 /
选课名单 / 统计报表 / Excel 导入导出。

1. **账号管理**：按角色筛选、按用户名或姓名搜索、翻页；「停用 / 启用」一键切换
   （不能停用自己；系统永远保留至少一个可用管理员）。
2. **学生 / 教师管理**：
   - 「+ 新增」：填写学号 / 工号与姓名 → 系统自动建登录账号（用户名 = 学号 / 工号，
     初始密码默认 `123456`，可自定义，创建成功后页面上会闪现提示）；
   - 「编辑」：改学号 / 工号会同步改用户名；填写新密码即重置口令；
   - 「删除」：连账号一起删除，学生的选课与成绩级联删除（有二次确认）；
     **仍授课的教师禁止删除**，需先在课程管理里更换授课教师或删除课程。
3. **课程管理**：新增时可选授课教师或「未排课」；编辑时容量不得小于已选人数；
   学期格式为 `年份-年份-序号`（如 `2025-2026-1`）；删除课程会连带删除选课与成绩（有提示）。
4. **选课名单**：从课程列表进入详情 → 「添加学生」代选 / 「移出课程」；
   **已出成绩的记录不能移出**。
5. **成绩录入**：课程详情页的名单即录入表单——顶部切换考核类型（平时 / 期中 / 期末），
   输入 0~100 的分数后保存；留空 = 不修改；无效分数会被逐条点名，其余照常保存。
6. **统计报表**：全校口径——汇总卡片、分数段分布、各课程平均分、班级排名。
7. **Excel 导入导出**：指引页有全课程快捷导出；每门课的导出 / 导入入口也在课程详情页。

## 3. 教师操作指南

导航：首页 / 我的课程 / 统计报表 / 成绩录入（指向我的课程）。

1. **我的课程**：只显示自己授课的课程；进入详情看到选课名单（**名单只读**，
   教师不能选课 / 退课 / 移人）。
2. **录成绩**：课程详情页 → 选考核类型 → 按学生输入分数 → 保存。
   - 同一类型重复保存 = 修改（自动覆盖，并记录操作人）；
   - 三种考核类型互不影响，切换时输入框按该类型已有分数预填；
   - 也可用 Excel：先「导出成绩」拿到名单文件 → 填分 → 「导入成绩」传回
     （学号必须在名单内、分数 0~100；错误行逐条报告，有效行照常导入）。
3. **成绩查看**：课程详情页随时核对；统计报表只覆盖自己授课的课程。
4. **权限边界**：访问他人课程的成绩录入 / 导入导出 → 403。

## 4. 学生操作指南

导航：首页 / 选课 / 我的课程 / 我的成绩 / 统计报表。

1. **选课**：「选课」页按关键词 / 学期筛选课程 → 点「选课」。
   - 已满或重复选会提示「名额已满 / 不能重复选课」；
   - 「我的课程」里可退课——**已出成绩的课程不能退**。
2. **查成绩**：「我的成绩」→ 按学期分组的成绩单，平时 / 期中 / 期末并列展示；
   已选未出成绩的课程显示「未录入」；页面上有「共修读 N 门 / 已出成绩 M 门」汇总。
3. **导出成绩单**：「我的成绩」页 → 「导出我的成绩单（Excel）」。
4. **课程详情**：能看到该课名单与自己各考核类型的成绩（只读）。
5. **统计报表**：仅本人范围——自己的成绩分布与已选课程的平均分。

## 5. 常见问题

**Q：`flask run` 报 `Could not locate a Flask application`**
必须在项目根目录执行，且 `.flaskenv` 存在。

**Q：首页提示"还有表未创建"**
执行 `flask init-db`；想清空重来用 `flask init-db --force` 后再 `flask seed`。

**Q：每次重启服务后都要重新登录？**
因为没配 `SECRET_KEY`（应用每次生成随机临时密钥并告警）。按 1.4 节配置 `.env` 即可。

**Q：登录提示"用户名或口令错误"但确信口令对**
账号可能被停用（提示不同：停用会明确说"该账号已被停用"）；或口令被重置过。
找管理员核对。

**Q：选课时显示"名额已满"**
课程容量已满（`容量 <= 0` 表示不限容量）；请等有人退课或联系管理员扩容。

**Q：成绩输错了能改吗？**
能。教师 / 管理员在同一考核类型下重新输入保存即可覆盖；操作人与时间自动记录。

**Q：Excel 导入报"第 N 行…不在本课程名单内"**
导入按「学号」列匹配本课程名单；名单外、空学号或手改了身份列都会被拒绝。
建议始终用「导出成绩」生成的文件填写后上传。

**Q：统计报表的图不显示**
图表走 CDN 加载 Chart.js；断网时图表为空，但所有数字仍在图下方的表格里（回退展示）。
