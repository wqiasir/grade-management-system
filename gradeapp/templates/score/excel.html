Excel 导入导出

当前身份：{{ role_label }} · 导出与导入都在课程详情页内完成；导出生成的文件就是导入模板。

使用说明

  1. 进入某门课的详情页（从「选课名单」进入），点「导出成绩」得到 .xlsx 文件； 空成绩的课程导出的也是完整名单，可直接当模板用；
  2. 在导出文件里填写 / 修改「平时 / 期中 / 期末」列（0~100 的数字，留空表示不修改）， 身份列（学号 / 姓名 / 班级）不要改动；
  3. 回到同一门课的详情页，「导入成绩」上传该文件：学号必须在课程名单内， 无效行会被逐条报告，有效行照常导入（部分保存）；
  4. 同一考核类型重复导入 = 更新（不是新增）；导入会记录操作人。

支持 .xlsx（openpyxl 读写）；加密或手工改动表头的文件会被拒绝并提示。
